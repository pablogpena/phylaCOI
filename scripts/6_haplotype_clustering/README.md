# Haplotype Clustering and Current-Zone Analysis

## Description
This step refactors the final phase 2 scripts into two reproducible drivers:

1. `run_all_haplotypes_clustering.R` clusters locality networks using all haplotype connections.
2. `run_same_vs_diff_currents.R` repeats the clustering separately for same-haplotype and different-haplotype connections, then compares current-zone and geographical-distance patterns.

Both scripts read the haplotype network tables generated in step 4.

## Input Structure
```
otus/
├── Phylum1/
│   └── haplotype_network/
│       ├── edges_Mi_filo.csv
│       └── points_Mi_filo.csv
└── Phylum2/
    └── haplotype_network/
        ├── edges_Mi_filo.csv
        └── points_Mi_filo.csv
```

These files are generated by `scripts/4_otu_metrics/get_div_abun_conn.R`.

## Usage

### 1. All Haplotypes
```bash
Rscript scripts/6_haplotype_clustering/run_all_haplotypes_clustering.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/all_haplotypes \
  --label metazoa
```

### 2. Same vs Different Haplotypes
```bash
Rscript scripts/6_haplotype_clustering/run_same_vs_diff_currents.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/same_vs_diff_currents \
  --all-output data/analysis/haplotype_clustering/all_haplotypes \
  --label metazoa
```

### Optional Ocean Metadata
If you have the original locality metadata, pass it to either script:

```bash
--metadata data/metadata_eKOI_ver2.csv
```

The metadata file must be semicolon-separated and contain `id_sample` and `Oceans`.

### Arguments
| Argument | Script | Type | Required | Description |
|-----------|--------|------|-----------|-------------|
| `-i`, `--input` | Both | Path | No (default: `data/otus`) | Root OTU directory containing per-phylum `haplotype_network/` folders. |
| `-o`, `--output` | Both | Path | No | Output directory for the selected analysis. |
| `--label` | Both | String | No (default: `metazoa`) | Suffix used in output filenames. |
| `--metadata` | Both | Path | No | Optional ocean metadata CSV with `id_sample` and `Oceans`. |
| `--sigma-grid` | Both | Comma list | No (default: `0.005,0.010,0.015`) | Candidate sigma values for RBF weighting. |
| `--k-moran` | Both | Integer | No (default: 5) | Number of nearest neighbors used for Moran's I. |
| `--seed` | Both | Integer | No (default: 42) | Random seed for Louvain clustering reproducibility. |
| `--no-maps` | All haplotypes | Flag | No | Skip static PDF map generation. |
| `--all-output` | Same vs diff | Path | No | Output directory from `run_all_haplotypes_clustering.R`; used for the combined current-zone figure. |
| `--no-current-figure` | Same vs diff | Flag | No | Skip the combined current-zone PNG figure. |

## Notes
- This step branches from step 4; it does not use `div_abun_conn_master.csv`.
- `group == "same"` means same haplotype found in different spatial clusters.
- `group == "diff"` means connected different haplotypes in the haplotype network.
- Static maps are skipped automatically if optional map packages are not installed.

## Requirements
- R >= 4.0
- Core R packages: dplyr, tidyr, igraph, ggplot2, geosphere, spdep, stringr, stringi
- Optional R packages: sf, scatterpie, rnaturalearth
