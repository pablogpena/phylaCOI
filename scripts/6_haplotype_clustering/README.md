# Haplotype Clustering

## Description
The scripts in this step analyze haplotype-network connectivity across sampling localities.  
They build locality-level networks from the haplotype edge and point tables generated in step 4, cluster localities with several edge-weighting strategies, and summarize how clusters relate to current zones and geographic distance.

This step is split into two commands:

1. `run_all_haplotypes_clustering.R` analyzes all haplotype connections together.
2. `run_same_vs_diff_currents.R` compares connections within the same haplotype against connections between different haplotypes.

## Input Requirements
The scripts expect the OTU output root produced by step 4:

```
otus/
├── Phylum1/
│   └── haplotype_network/
│       ├── haplotype_edges.csv
│       └── haplotype_points.csv
│
├── Phylum2/
│   └── haplotype_network/
│       ├── haplotype_edges.csv
│       └── haplotype_points.csv
│
└── ...
```

These files are generated by `scripts/4_otu_metrics/get_div_abun_conn.R`.

The ocean metadata file must be semicolon-separated and contain:

| Column | Description |
|--------|-------------|
| `id_sample` | Locality or sample identifier matching the network tables. |
| `Oceans` | Ocean category assigned to each locality. |

In the standard project layout, this file is expected in `data/raw/ocean_metadata.csv`.
It is required by `run_all_haplotypes_clustering.R` and optional for `run_same_vs_diff_currents.R`.

## Usage

### 1. All Haplotype Connections
```bash
Rscript scripts/6_haplotype_clustering/run_all_haplotypes_clustering.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/all_haplotypes \
  --metadata data/raw/ocean_metadata.csv
```

#### Arguments

| Argument | Type | Required | Description |
|-----------|------|-----------|-------------|
| `-i`, `--input` | Path | No (default: `data/otus`) | Root OTU directory containing one folder per phylum. |
| `-o`, `--output` | Path | No | Directory where all-haplotype outputs will be written. |
| `--metadata` | Path | Yes | Ocean metadata CSV with `id_sample` and `Oceans`. |
| `--sigma-grid` | Comma list | No (default: `0.005,0.010,0.015`) | Candidate sigma values for RBF edge weighting. |
| `--k-moran` | Integer | No (default: `5`) | Number of nearest neighbors used for Moran's I. |
| `--no-maps` | Flag | No | Skip static PDF map generation. |

#### Outputs
The all-haplotype command writes the following outputs to `analysis/haplotype_clustering/all_haplotypes/`:
All output filenames use the `metazoa` suffix.

| File | Description |
|------|-------------|
| `edges_with_info.csv` | Haplotype edges joined with locality, OTU, phylum, and coordinate information. |
| `points_all.csv` | Haplotype point table combining all processed phyla. |
| `clusters_metazoa.csv` | Locality cluster assignments for all weighting methods. |
| `clusters_metazoa_with_coordinates.csv` | Cluster assignments with locality coordinates. |
| `ari_metazoa.csv` | Adjusted Rand Index comparisons between clustering methods. |
| `modularity_summary_metazoa.csv` | Best modularity summary for each weighting method. |
| `modularity_results_metazoa.csv` | Full modularity table across tested settings. |
| `rbf_sigma_grid_metazoa.csv` | RBF sigma-grid results. |
| `moran_inverse_metazoa.csv` | Moran's I results for inverse-distance clusters. |
| `moran_count_metazoa.csv` | Moran's I results for connection-count clusters. |
| `moran_linear_metazoa.csv` | Moran's I results for linear-weight clusters. |
| `moran_rbf_metazoa.csv` | Moran's I results for RBF-weight clusters. |
| `locality_zones_currents_all.csv` | Current-zone assignment for each locality. |
| `zone_share_<method>_metazoa.csv` | Current-zone proportions by cluster and method. |
| `ocean_coordinates_<method>_metazoa.csv` | Ocean-category proportions by cluster and method. |

If maps are enabled, the script writes:

```
figures/
├── map_inverse_1d_metazoa.pdf
├── map_connections_metazoa.pdf
├── map_linear_metazoa.pdf
└── map_rbf_metazoa.pdf
```

### 2. Same-Haplotype vs Different-Haplotype Connections
Run this command after the all-haplotype analysis:

```bash
Rscript scripts/6_haplotype_clustering/run_same_vs_diff_currents.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/same_vs_diff_currents \
  --all-output data/analysis/haplotype_clustering/all_haplotypes
```

With optional ocean metadata:

```bash
Rscript scripts/6_haplotype_clustering/run_same_vs_diff_currents.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/same_vs_diff_currents \
  --all-output data/analysis/haplotype_clustering/all_haplotypes \
  --metadata data/raw/ocean_metadata.csv
```

#### Arguments

| Argument | Type | Required | Description |
|-----------|------|-----------|-------------|
| `-i`, `--input` | Path | No (default: `data/otus`) | Root OTU directory containing one folder per phylum. |
| `-o`, `--output` | Path | No | Directory where same-vs-different outputs will be written. |
| `--all-output` | Path | No | Output directory from `run_all_haplotypes_clustering.R`, used for the combined current-zone figure. |
| `--metadata` | Path | No | Optional ocean metadata CSV with `id_sample` and `Oceans`. |
| `--sigma-grid` | Comma list | No (default: `0.005,0.010,0.015`) | Candidate sigma values for RBF edge weighting. |
| `--k-moran` | Integer | No (default: `5`) | Number of nearest neighbors used for Moran's I. |

#### Outputs
The same-vs-different command writes the following outputs to `analysis/haplotype_clustering/same_vs_diff_currents/`:
All output filenames use the `metazoa` suffix.

| File | Description |
|------|-------------|
| `edges_with_info.csv` | Haplotype edges joined with locality, OTU, phylum, and coordinate information. |
| `locality_zones_currents.csv` | Current-zone assignment for localities used in the analysis. |
| `modularity_same_diff_summary_metazoa.csv` | Modularity summary for same-haplotype and different-haplotype networks. |
| `ari_same_within_methods_metazoa.csv` | ARI comparisons among methods using same-haplotype edges. |
| `ari_diff_within_methods_metazoa.csv` | ARI comparisons among methods using different-haplotype edges. |
| `ari_same_vs_diff_by_method_metazoa.csv` | ARI comparisons between same and different networks for each method. |
| `moran_same_<method>_metazoa.csv` | Moran's I results for same-haplotype clusters. |
| `moran_diff_<method>_metazoa.csv` | Moran's I results for different-haplotype clusters. |
| `locality_coords_same_<method>.csv` | Locality coordinates and clusters for same-haplotype networks. |
| `locality_coords_diff_<method>.csv` | Locality coordinates and clusters for different-haplotype networks. |
| `zone_share_same_<method>_metazoa.csv` | Current-zone proportions for same-haplotype clusters. |
| `zone_share_diff_<method>_metazoa.csv` | Current-zone proportions for different-haplotype clusters. |
| `geographic_distance_medians_by_OTU_metazoa.csv` | Median geographic distance by OTU and connection group. |
| `geographic_distance_median_summary_by_OTU_metazoa.csv` | Summary of OTU-level geographic distance medians. |
| `geographic_distance_statistics.csv` | Statistical comparison of geographic distances by connection group. |
| `p_dist_metazoa.pdf` | Geographic-distance distribution plot. |
| `Figure_currents_all_methods_ALL_same_diff_ALLgroups.png` | Combined current-zone figure across methods and connection groups. |

If `--metadata` is provided:

| File | Description |
|------|-------------|
| `ocean_share_same_<method>_metazoa.csv` | Ocean-category proportions for same-haplotype clusters. |
| `ocean_share_diff_<method>_metazoa.csv` | Ocean-category proportions for different-haplotype clusters. |

## Notes
- This step uses the haplotype-network tables from step 4; it does not use `div_abun_conn_master.csv`.
- The article results were generated with `--sigma-grid 0.005,0.010,0.015`, `--k-moran 5`, and a fixed Louvain seed of `42`.
- `group == "same"` indicates connections between observations assigned to the same haplotype.
- `group == "diff"` indicates connections between different haplotypes in the haplotype network.
