# phylaCOI

This repository accompanies the paper entitled *XXXXX*. It contains the code and documentation used to process COI metabarcoding sequences, assign taxonomy, estimate sequence abundance, generate OTUs, compute OTU-level metrics, and perform downstream metric and haplotype-clustering analyses.

The repository is provided to make the analyses presented in the paper reproducible and to enable similar analyses using compatible data. Each pipeline step has its own README with detailed inputs, arguments, outputs, and requirements. This global README summarizes the complete analysis pipeline and the commands needed to run it from the repository.

## Running phylaCOI

The analyses can be reproduced in two ways:

- **Modular pipeline:** run each script separately from the terminal. This is useful for inspecting intermediate files, changing one stage at a time, or rerunning a specific step.
- **Nextflow workflow:** run the complete pipeline automatically with [Nextflow](https://www.nextflow.io/), a workflow manager that connects steps through their input and output files, records completed tasks, and can resume interrupted runs.

Both modes use the same input files, analysis scripts, and output structure. Nextflow automates the execution; it does not change the analyses.

## Repository Structure

At the top level, the repository is organized into four main working areas:

| Folder | Description |
|--------|-------------|
| `data/` | Input data, intermediate files, and final analysis outputs generated by the pipeline. |
| `scripts/` | Executable scripts, organized by pipeline step. |
| `src/` | Shared functions and helper code used by the scripts. |
| `nextflow/` | Automated Nextflow implementation of the complete pipeline. |

The `data/` folder is further organized by stage:

| Folder | Description |
|--------|-------------|
| `data/raw/` | Initial input files provided by the user. |
| `data/procesed/` | Cleaned FASTA files generated during raw data processing. |
| `data/vsearch_results/` | Taxonomic assignment results and phylum-specific FASTA files. |
| `data/abundance/` | Per-phylum abundance tables, unique sequences, and MAFFT alignments. |
| `data/otus/` | OTU outputs, informative OTUs, OTU metrics, and haplotype-network tables. |
| `data/analysis/` | Final analysis tables, plots, maps, and summary figures. |

## Pipeline Overview

The modular pipeline consists of six stages. The first four stages transform the raw COI sequences into OTUs and OTU-level metrics. Stage 4 then provides the inputs for two independent downstream analyses: metrics analysis and haplotype clustering.

```text
1. Raw data processing
        ↓
2. Abundance estimation
        ↓
3. OTU generation
        ↓
4. OTU metrics
        ├── 5. Metrics analysis
        └── 6. Haplotype clustering
```

## Modular Pipeline

Run the following commands from the repository root to execute each stage separately.

### 1. Raw Data Processing

Clean FASTA identifiers and save the original sequence headers:

```bash
python scripts/1_raw_data_processing/fasta_preprocess.py \
  -i data/raw/eKOI_metabarcoding.fasta \
  -t data/raw/seq_headers.txt \
  -o data/procesed/eKOI_metabarcoding_cleaned.fasta
```

Assign taxonomy with VSEARCH and split sequences into phylum folders:

```bash
python scripts/1_raw_data_processing/vsearch_taxonomy.py \
  -d data/raw/eKOI_database.fasta \
  -i 0.84 \
  -f data/procesed/eKOI_metabarcoding_cleaned.fasta \
  -o data/vsearch_results/
```

More details: [raw data processing](scripts/1_raw_data_processing/readme.md)

### 2. Abundance Estimation

Create per-phylum abundance tables, unique-sequence FASTA files, and MAFFT alignments:

```bash
python scripts/2_abundance_estimation/get_abundance.py \
  -i data/vsearch_results \
  -o data/abundance \
  -n data/raw/seq_headers.txt \
  -m data/raw/KOI_metadata.csv \
  -a 1
```

More details: [abundance estimation](scripts/2_abundance_estimation/readme.md)

### 3. OTU Generation

Cluster aligned sequences into OTUs:

```bash
python scripts/3_otu_generation/generate_otus.py \
  -a data/abundance \
  -o data/otus \
  -i 0.97
```

Identify informative OTUs for downstream analyses:

```bash
Rscript scripts/3_otu_generation/get_informative_otus.R \
  -a data/abundance \
  -o data/otus
```

More details: [OTU generation](scripts/3_otu_generation/README.md)

### 4. OTU Metrics

Compute diversity, abundance, and haplotype-connection metrics for informative OTUs:

```bash
Rscript scripts/4_otu_metrics/get_div_abun_conn.R \
  -a data/abundance \
  -o data/otus
```

This step writes:

- per-phylum OTU metrics to `data/otus/<phylum>/informative_otus_metrics/`
- per-phylum haplotype-network inputs to `data/otus/<phylum>/haplotype_network/`
- the combined metrics table to `data/otus/div_abun_conn_master.csv`

More details: [OTU metrics](scripts/4_otu_metrics/README.md)

### 5. Metrics Analysis

Analyze the combined OTU metrics table across phyla:

```bash
Rscript scripts/5_metrics_analysis/analyze_otu_metrics.R \
  -i data/otus/div_abun_conn_master.csv \
  -o data/analysis/otu_metrics_summary \
  --min-otus 10
```

More details: [metrics analysis](scripts/5_metrics_analysis/README.md)

### 6. Haplotype Clustering

Run all-haplotype clustering:

```bash
Rscript scripts/6_haplotype_clustering/run_all_haplotypes_clustering.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/all_haplotypes \
  --metadata data/raw/ocean_metadata.csv
```k

Run same-haplotype vs different-haplotype clustering:

```bash
Rscript scripts/6_haplotype_clustering/run_same_vs_diff_currents.R \
  -i data/otus \
  -o data/analysis/haplotype_clustering/same_vs_diff_currents \
  --all-output data/analysis/haplotype_clustering/all_haplotypes
```

More details: [haplotype clustering](scripts/6_haplotype_clustering/README.md)

## Nextflow Execution

The Nextflow workflow automates the same six pipeline stages described in the modular pipeline above. It uses the default input paths in `data/raw/` and writes the standard outputs under `data/`. For input parameters, custom runs, outputs, and environment details, see [Nextflow](nextflow/README.md).

<img src="./nextflow/assets/PhylcaCOI_NextFlow.svg" alt="phylaCOI Nextflow workflow" width="100%">

First, create and activate the workflow environment from the repository root:

```bash
micromamba env create -f nextflow/environment.yml
micromamba activate phylaCOI
```

Then, run the complete pipeline:

```bash
nextflow run nextflow/main.nf \
  -c nextflow/nextflow.config
```

To resume an interrupted execution, run the same command with `-resume`:

```bash
nextflow run nextflow/main.nf \
  -c nextflow/nextflow.config \
  -resume
```
