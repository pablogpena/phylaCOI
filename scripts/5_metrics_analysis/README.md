# analyze_otu_metrics.R

## Description
`analyze_otu_metrics.R` summarizes the combined OTU metrics across all phyla.  
It fits multiple models per metric, generates predictions and plots, computes Spearman correlations,
and runs permutation tests on slope differences between metrics.  
Optionally, it can also generate heatmaps from a precomputed phylum-comparison table.

## Input Requirements
The script expects a combined metrics table produced in step 4:

```
otus/
└── div_abun_conn_master.csv
```

This file is generated by `scripts/4_otu_metrics/get_div_abun_conn.R`.

Optionally, you can provide a phylum-comparison table with columns:
`phylum1`, `phylum2`, `observed_diff`, `p_value`, `model`, `metric`.

## Usage

### Basic Command
```bash
Rscript scripts/5_metrics_analysis/analyze_otu_metrics.R \
  -i data/otus/div_abun_conn_master.csv \
  -o data/analysis/otu_metrics_summary \
  --min-otus 10
```

### With Phylum Comparison Heatmaps
```bash
Rscript scripts/5_metrics_analysis/analyze_otu_metrics.R \
  -i data/otus/div_abun_conn_master.csv \
  -o data/analysis/otu_metrics_summary \
  --comparisons data/analysis/phylum_comparisons.csv \
  --heatmap-model nls \
  --heatmap-metrics scaled_diversity,scaled_log_abundance
```

### Arguments
| Argument | Type | Required | Description |
|-----------|------|-----------|-------------|
| `-i`, `--input` | Path | Yes | Path to the combined metrics CSV (`div_abun_conn_master.csv`). |
| `-o`, `--output` | Path | Yes | Output directory for summary tables and plots. |
| `--min-otus` | Integer | No (default: 10) | Minimum number of unique OTUs required per phylum to include it in analyses. |
| `--comparisons` | Path | No | Optional phylum-comparison CSV for heatmaps. |
| `--heatmap-model` | String | No (default: `nls`) | Model to filter in the phylum-comparison heatmaps. |
| `--heatmap-metrics` | Comma list | No | Comma-separated list of metric names to plot (defaults to all in the file). |

## Output
The script writes summary tables and plots to the output directory.
Only phyla with at least `--min-otus` unique OTUs are included in downstream analyses.

Core outputs:
- `model_fit_summary.csv`
- `model_predictions_long.csv`
- `model_comparison_by_phylum.pdf`
- `spearman_correlations.csv`
- `spearman_correlation_<var1>_vs_<var2>.pdf`
- `spearman_correlation_heatmap.pdf`
- `spearman_correlation_network.pdf`
- `metric_slope_permutation_tests.csv`
- `metric_slopes_by_model.csv`

If a comparison file is provided, additional heatmaps and matrices are written:
- `phylum_comparisons_<model>_<metric>_heatmap.pdf`
- `phylum_comparisons_<model>_<metric>_heatmap_dendrogram.pdf`
- `phylum_comparisons_<model>_<metric>_observed_diff.csv`
- `phylum_comparisons_<model>_<metric>_p_value.csv`
